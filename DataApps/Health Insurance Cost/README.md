# Health Insurance Cost Prediction

This project explores health insurance data and builds a machine-learning model to estimate insurance payments.

## Contents

- `NoteBooks/` — analysis and model-training notebooks
- `NoteBooks/src/app.py` — Streamlit prediction app
- `Data/` — project dataset, if included

## Run the app

From the repository root:

```bash
./.venv/Scripts/python.exe -m streamlit run "DataApps/Health Insurance Cost/NoteBooks/src/app.py"
```

The app requires its trained model and preprocessing `.pkl` files in the `NoteBooks/src/` folder.

This project is for educational purposes. Predictions are estimates, not financial advice.
