# Data Science Projects

Welcome to my data science repository. I use this space to share projects focused exclusively on exploring data, building models, and communicating insights.

## What you’ll find here

Projects may include:

- Data cleaning and preparation
- Exploratory data analysis and visualizations
- Statistical analysis
- Machine-learning models and evaluation
- Data-driven applications and dashboards
- Notebooks, code, and project documentation

Each project is organized in its own folder and may use different tools or datasets. Check its documentation for details, setup instructions, and how to run it.

## Tools and technologies

Depending on the project, I may use Python and libraries such as pandas, NumPy, Matplotlib, Seaborn, scikit-learn, and Streamlit.

## Note

Projects are for learning and demonstration. Findings and model predictions depend on the data and methods used, and should not automatically be treated as professional advice.
